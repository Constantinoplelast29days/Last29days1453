# The Last 29 Days of Constantinople

**Oyna:** https://constantinoplelast29days.github.io/Last29days1453/

1453 Konstantinopolis kuşatmasının son günlerinde geçen tarihî, etkileşimli bir hikâye. Şehirde yaşayan kurgusal bir sivili izlersin; seçimlerin karakterin deneyimini şekillendirir, tarihin sonucunu değil. İngilizce ve Türkçe oynanabilir. Saf HTML, CSS ve JavaScript ile yazıldı; derleme gerekmez, `index.html` tarayıcıda açılarak çalışır.

- Hikâye eklemek için [HIKAYE-EKLEME.md](HIKAYE-EKLEME.md)'ye bak.
- Görseller yapay zekâ taslağıdır, nihai değildir.
